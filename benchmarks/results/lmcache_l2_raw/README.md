# Raw LMCache L2 benchmark data

The results pages in `benchmarks/results/` hold the numbers. This folder keeps a sample of the raw
output behind them: every text summary, and one JSON result per run directory, so the format and
the settings of each run can be checked.

The full set (802 files, mostly one JSON and one CPU sample per run) was removed from the branch
to keep pull requests reviewable. It is archived outside the repository and can be attached to a
release on request.
